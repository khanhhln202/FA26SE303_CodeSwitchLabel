II. Software Requirement Specification
1. Product Overview
CodeSwitchLabel is a web system for collecting and quality-controlling a Vietnamese–English
code-switching speech corpus for Automatic Speech Recognition (ASR) training.


Vietnamese speakers frequently mix English words into Vietnamese sentences ("Em nên **scan** tài
liệu này"). Speech recognisers trained on monolingual Vietnamese handle these utterances poorly,
and no sizable open corpus of such speech exists. The system organises the work of building one:
collecting sentence pairs, assigning recording work, capturing audio, and putting every recording
through independent human review before it can enter a released dataset.


The unit of data is a **sentence pair**: a code-switched sentence and its pure-Vietnamese
equivalent, carrying a word-level alignment between the English words and their Vietnamese
meanings. Both halves of a pair are read by the **same speaker**, so the two recordings differ only
in wording, not in voice. A pair is usable only when both recordings are approved.

2. User Requirements
2.1 Actors
#
	Actor
	Description
	1
	Speaker
	Reviews assigned sentence pairs, suggests corrections or reports problems, records the Vietnamese–English code-switching sentence and its Vietnamese equivalent, and tracks personal progress and recording history.

	4

	Manages users and roles, sentence data, campaigns, datasets, and system settings. The Administrator can also view dashboards and quality statistics.

3.1.4 Non-Screen Functions
#
	Feature
	System Function
	Description
	1
	Authentication
	Token Issuance & Validation
	Issues a signed token (for example JWT) after a successful login and validates it on every API request.
	2
	Authentication
	Role-Based Access Control
	Middleware that checks the user's role against the requested API and blocks unauthorized access.
	3
	Authentication
	Password Hashing
	Stores passwords as salted hashes and verifies them on login and password change.
	4
	Text Management
	Sentence Validation
	Checks every new or edited sentence: required fields, Vietnamese-English mix, and the English word limit from System Configuration.
	5
	Text Management
	Duplicate Detection
	Normalizes text and rejects sentences that already exist in the corpus, for both contributions and imports.
	6
	Text Management
	JSON Import Processing
	Parses an uploaded JSON file, validates each sentence, and inserts the valid ones. Returns a report of accepted and rejected rows with reasons.
	7
	Recording
	Next Sentence Allocation
	Picks the next sentence for a Speaker from the assigned task, skipping sentences already recorded and keeping the topic distribution balanced.
	8
	Recording
	Sentence Reservation
	Temporarily locks a sentence while a Speaker works on it, so concurrent Speakers do not get the same one. Expires the lock if the Speaker goes idle.
	9
	Recording
	Audio Upload & Storage
	Receives the submitted audio, saves it to object storage, and stores the metadata (speaker, sentence, duration, path) in PostgreSQL.
	10
	Recording
	Audio Normalization
	Converts uploaded audio to a standard format (for example WAV, 16 kHz, mono) for consistent processing and training.
	11
	Recording
	Automatic Audio Quality Check
	Computes duration, silence ratio, clipping, and estimated noise level. Flags recordings that fail basic thresholds before they reach a Reviewer.
	12
	Review
	Review Assignment & Sampling
	Distributes recordings to Reviewers per task and draws random samples for quick review. Prevents a Reviewer from reviewing their own recordings.
	13
	Review
	Contribution Approval Processing
	When a Reviewer approves a contributed sentence, adds it to the text corpus. When an edit proposal is accepted, updates the sentence and keeps the old version in history.
	14
	Review
	Rejection Handling
	Marks a rejected recording or sentence, saves the reason, and returns the item to the Speaker's queue for re-recording or revision.
	15
	Task Management
	Progress Calculation
	Recalculates each user's completed count against their target whenever a recording is submitted or reviewed. Feeds the Task Dashboard and Review Dashboard.
	16
	Task Management
	Deadline Monitoring Job
	Scheduled job (cron) that marks tasks as overdue and sends reminders as deadlines approach.
	17
	Dataset
	Dataset Build & Export
	Collects approved recordings, applies the train/dev/test split, generates a manifest file (CSV/JSON) with audio path and transcript), and packages the dataset for download.
	18
	Statistics
	Statistics Aggregation Job
	Scheduled job (Python) that computes totals, recording duration, approval rate, common rejection reasons, and per-Speaker quality. Caches the results for the dashboards.
	19
	Audit
	History & Audit Logging
	Records every change to recordings, reviews, sentences, and configuration (who, what, when, old and new value) to keep complete histories.
